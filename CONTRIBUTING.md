# Contributing to AutoTablature

Thank you for your interest in contributing to AutoTablature! This document provides guidelines and instructions for contributing to this project.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and considerate to all contributors.

## Getting Started

1. **Set up your development environment**
   - Fork the repository
   - Clone your fork: `git clone https://github.com/YOUR-USERNAME/autotablature.git`
   - Set up the development environment using DevContainer (see README.md)

2. **Find an issue to work on**
   - Check the [Issues](https://github.com/webprofusion/autotablature/issues) page
   - Look for issues labeled "good first issue" if you're new to the project

3. **Create a branch for your work**
   - Create a new branch: `git checkout -b feature/your-feature-name`
   - Use descriptive branch names that reflect the changes you're making

## Development Workflow

1. **Make your changes**
   - Follow the code style guidelines (PEP 8 for Python)
   - Include type hints for all functions and methods
   - Write docstrings for all functions, classes, and modules

2. **Test your changes**
   - Add unit tests for new functionality
   - Ensure all tests pass: `pytest tests/`
   - Run the example scripts to verify functionality

3. **Document your changes**
   - Update relevant documentation
   - Add comments explaining complex logic

## Submitting Your Contribution

1. **Commit your changes**
   - Use clear, concise commit messages
   - Reference issue numbers in commit messages

2. **Create a pull request**
   - Push your branch to your fork: `git push origin feature/your-feature-name`
   - Create a pull request from your fork to the main repository
   - Provide a clear description of the changes and their purpose

3. **Code review**
   - Address any feedback from the maintainers
   - Make necessary revisions
   - Maintain a respectful dialogue during the review process

## Reporting Issues

If you find a bug or have a suggestion for improvement:

1. Check the [Issues](https://github.com/webprofusion/autotablature/issues) page to see if it has already been reported
2. If not, create a new issue with:
   - A clear, descriptive title
   - Detailed steps to reproduce the issue
   - Expected vs. actual behavior
   - Screenshots or error messages, if applicable
   - Your environment (OS, Python version, etc.)
